# Remotion art preview

Node.js + npm: `npm install`, then `npm run studio`.
Export the concept board: `npm run still`.
Export poses: `npx remotion still src/index.ts MomoPoses out/momo.png`.
`ArtWalkthrough` is a 10-second composition available for later video export; no video is delivered or required by the current request.
All artwork is a draft for review. Files in public are exact copies of ../art/concepts.

Verification: TypeScript passed and Remotion bundling completed. Still rendering was blocked in this execution environment by `uv_interface_addresses` (local network interface access). Run the commands on your own development machine. The delivered PNGs are the original generated concepts, not Remotion renders.
